# RosterMaker

選手画像をアップロードして1920×1080のロスター画面を表示します。

- A〜Jの画像を選択（JPG / PNG / WebP、各5MB以下）。画像の差し替え・削除に対応。
- 選手名・ロール・チーム名・チームアイコン・スコアを編集できます。
- 表示画面は1920×1080の比率を保ってウィンドウ内に表示します。画像は枠いっぱいに表示され、端が切り取られる場合があります。
- 長押し、またはEscapeキーで「入力に戻る」を表示します。
- 画像はブラウザ内で扱います。サーバーへの送信や永続保存は行わず、再読み込みすると初期値に戻ります。
- GitHub Pagesはmainブランチのルートを公開対象に指定します。
